# apps/web

Плейсхолдер для будущего веб-приложения SHOPCRM.

Структура намеренно не привязана к конкретному стеку:

- **FastAPI** — размещается здесь как `apps/web/src/shopcrm_web/`
  (Python-пакет, зависит от `shopcrm-core`, переиспользует домен и БД).
- **Next.js / React** — размещается здесь как отдельный Node-проект
  (общение с бэкендом через API).

Правило зависимостей: веб-приложение может зависеть от `shopcrm-core`,
но никогда — от `shopcrm-bot`.
