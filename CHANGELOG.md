# Changelog

Все значимые изменения проекта документируются в этом файле.

## [0.1.3] - 2026-09-26

### Added

- Уведомление администраторов о новом заказе: при оформлении заказа
  (`checkout_confirm`) каждому админу в фоне (не блокируя ответ клиенту)
  отправляется карточка заказа с кнопкой «📋 Перейти к заказу»
  (callback `admin_order_view:{order_id}`, открывает существующий
  админ-хендлер просмотра заказа). Уведомление на языке каждого админа
  (EN — по умолчанию); ошибка отправки одному админу логируется и не
  блокирует остальных
- Меню команд бота (`/` в чате):
  - `/start` — глобально для всех пользователей (выставляется при старте
    бота)
  - `/admin` — только для администраторов, через per-chat scope
    (`BotCommandScopeChat`); выставляется в `DbSessionMiddleware` с
    in-memory кэшем (повторные API-вызовы не дёргаются; смена языка или
    прав админа — команды переставляются)
- Тесты: `tests/test_new_order_notification.py` (язык админа, кнопка
  заказа, изоляция ошибок, отсутствие заказа) и `tests/test_bot_commands.py`
  (состав команд, per-chat scope, кэш, middleware)

## [0.1.2] - 2026-09-12

### Changed

- Дефолтный язык интерфейса теперь `en` (был `ru`); фолбэк при отсутствии
  перевода всегда на `en`
- Удалена настройка `NOTIFICATIONS_LANG`: уведомления администраторам
  (оплата, отмена) теперь отправляются на языке каждого администратора
  (из БД)
- Новый пользователь создаётся с `language=None`: при первом `/start`
  показывается выбор языка, после выбора язык сохраняется в БД
- Кнопка «Менеджер» в карточке товара настраивается переменной окружения
  `MANAGER_URL`; если не задана — кнопка скрывается (ранее URL был
  захардкожен)

### Fixed

- `IsAdminFilter`: сигнатура `__call__` теперь принимает `admin_ids`
  напрямую (kwarg из workflow data), а не `data: Dict`. aiogram 3 передаёт
  workflow data поимённо и ключ `data` не содержит → на любом сообщении
  (включая клиентские) возникал `TypeError`, т.к. root-фильтр админ-роутера
  проверяется для всех событий. Добавлены регрессионные тесты
  (`tests/test_admin_filter.py`).
- Packaging `shopcrm-core`: `locales/locale.json` теперь включается в wheel
  (`[tool.setuptools.package-data]`). Ранее файл не попадал в установленный
  пакет, из-за чего `Locale` молча падал на пустой словарь и обработчик
  ошибок бота крешил с `FileNotFoundError`

## [0.1.1] - 2026-09-11

### Changed

- Администраторы теперь передаются через workflow data (`admin_ids`):
  `DbSessionMiddleware` принимает опциональный параметр `admin_ids`
  (нужен для мульти-тенантового хостинга). Self-hosted поведение не
  изменилось — по умолчанию используется `config.ADMIN_ID`
- `IsAdminFilter`, уведомления об оплате/отмене и ответ клиента
  администратору используют инжектированные `admin_ids`
  (фолбэк на `config.ADMIN_ID`)

## [0.1.0] - 2026-09-07

### Added

- Каталог товаров с категориями и поиском
- Корзина: добавление, изменение количества, удаление
- Оформление заказа: адрес доставки, комментарий, расчёт итога
- Оплата: прикрепление чека (фото / текст), подтверждение администратором
- История заказов со статусами и чатом с поддержкой
- Админ-панель: CRUD товаров и категорий, управление статусами заказов
- Мультиязычность (RU / EN) с переключением в боте
- Настройки через `.env` (pydantic-settings)
- Асинхронная БД (SQLAlchemy 2.0 + asyncpg / aiosqlite)
- Миграции (Alembic)
- Тестовый набор: 44 теста (расчёты, ownership, локализация, конфиг)
